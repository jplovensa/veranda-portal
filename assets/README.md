# Presentation assets

The application expects the original project images, five MP4 films and Inter font in this directory. Binary transfer is pending browser upload capability. Keep this repository private; the project media is not licensed for public redistribution.

Folder layout: `assets/*.jpg`, `assets/secha.png`, `assets/film-1.mp4` through `film-5.mp4`, `assets/fonts/Inter-Variable.ttf` and `assets/fonts/OFL.txt`.
