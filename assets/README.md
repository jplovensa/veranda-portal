# Presentation assets

All 26 original media and font files are included in `../veranda-assets.zip`. Run `npm run dev` or `node prepare-assets.mjs` from the repository root to verify and unpack this archive. Extracted files are ignored by Git; the archive is the canonical source.

The bundle includes five MP4 concept films, JPG renders and material images, SECHA branding, and `fonts/Inter-Variable.ttf` with its SIL Open Font License. Keep the repository private. Project media is not licensed for public redistribution.
